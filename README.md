🪨 Inkstone (砚台)
墨聚于此，知识有价。
基于 TypeScript 全栈自研的现代化付费阅读平台，专注于提供纯粹、轻量且完全私有的内容创作与变现体验。

Inkstone 是一个基于 Next.js 14 (App Router) + TypeScript + Prisma + PostgreSQL 构建的个人知识付费博客系统。原生接入会员认证与支付闭环，致力于为你提供完全掌控的写作与变现基础设施。

✨ 核心特性 (规划中)
📝 纯粹写作：原生支持 Markdown，专注内容本身。

🔒 知识付费：支持单篇文章付费阅读、毛玻璃遮罩拦截。

👤 用户体系：基于 NextAuth 的完整登录与会员状态管理。

🚀 极速体验：由 Vercel 驱动，边缘网络极速渲染，首屏秒开。

🎨 完全掌控：代码全栈开源，随心所欲定制你的专属视觉。
